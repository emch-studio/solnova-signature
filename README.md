# Signatures mail SolNova Ingénierie : images

Ce dépôt héberge les images des signatures mail de SolNova Ingénierie : volets, pictogrammes, encarts et photo. Les signatures les chargent depuis cette adresse :

https://emch-studio.github.io/solnova-signature/

Les messageries (Gmail notamment) ne gardent pas les images d'une signature : elles les téléchargent à chaque affichage, sans se connecter. Les images doivent donc être publiques. Elles ne contiennent rien d'autre que ce que voit chaque destinataire d'un mail.

**Hébergement provisoire**, assuré par EMCH en attendant le site de SolNova.

## Règles

- Ne jamais renommer ni supprimer un fichier : les mails déjà envoyés pointent vers ces noms.
- Une nouvelle version d'une image prend un nouveau nom ; l'ancienne reste en place.

## À changer à la sortie du site

1. Déposer ces images sur le site de SolNova.
2. Régénérer les signatures avec la nouvelle adresse et les réinstaller dans les messageries.
3. Garder ce dépôt public et en ligne : les mails envoyés avant le changement continuent d'y lire leurs images.
